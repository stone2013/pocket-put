# 袖珍果岭 · Pocket Putt 1.0.3

一颗小球，九座小花园。使用提供的 Kenney Minigolf Kit 制作的离线 3D 迷你高尔夫小游戏。

## 1.0.3 阴影稳定性修复

修复调整瞄准方向时阴影整帧消失，以及转动视角时草坪出现跳动暗点的问题。正常的动态阴影继续保留，没有关闭投影。九洞关卡、滚动物理、输入方式、素材和存档键未改变。

将新版 `index.html` 替换旧版即可更新网站。在本地运行时，保留原来的文件位置与名称更有利于沿用浏览器存储；跨路径的本地文件存档是否共享由浏览器决定，本版不做跨来源迁移。

技术记录见 `CHANGELOG.md` 和 `QA_REPORT.md`。`QA_REPORT_v1.0.md` 及未带版本号的旧测试 JSON 是原版历史记录，不代表本次新增测试。

## 开始游戏

在电脑上用支持 WebGL 的浏览器打开 `index.html`。游戏本体只有这一个 HTML 文件，模型、颜色、程序和音效均已内置，不需要安装依赖、启动服务器或连接外网。

手机已经提供竖屏界面、触屏拉杆和双指视角控制。手机端建议把 `index.html` 放到静态网站后，在浏览器中访问；本次交付不包含一个已部署的公网网址。手机文件管理器里的文件预览不作为运行环境。

需要浏览器允许 WebGL 图形渲染。若提示图形环境不可用，可检查浏览器的硬件加速设置。没有 WebGL 时会显示错误提示，不会假装已经进入游戏。

## 操作

| 操作 | 方法 |
| --- | --- |
| 拉杆击球 | 在球场上按住并向后拖动，松开击球；拉得越远，力度越大 |
| 精确击球 | 点击球道设定方向，调整底部力度滑杆，点击“击球” |
| 键盘 | 左右方向键微调瞄准；上下方向键调整力度；空格击球；按住 Shift 可更细地微调 |
| 旋转视角 | 电脑右键拖动，或按 Q / E，或点旋转按钮 |
| 缩放 | 电脑滚轮；手机双指捏合 |
| 手机旋转 | 双指左右平移 |
| 暂停 | 右上角暂停按钮或 Esc |
| 辅助线 | 右下角准星按钮开关 |

球停稳后才能击下一杆。移动转臂能够撞动静止的小球。辅助线使用同一套滚动物理预测，移动障碍仍然需要把握时机。

## 计分与存档

- 九洞巡回赛按顺序进行，进洞后结算；最后显示整场记分卡。
- 自由选洞进入练习，不覆盖巡回赛。个人最佳成绩单独记录。
- 落水返回上一杆起点，并加罚 1 杆。
- 手动返回发球点保留已有杆数，并加罚 1 杆。
- 每洞封顶 12 杆，避免卡关。
- 停球后、完成球洞后会保存巡回赛进度；在同一浏览器环境中打开可以继续。
- 存档使用浏览器 localStorage，不是云存档。隐私模式、清理站点数据、换浏览器、改变访问来源或移动本地文件可能影响存档可用性。
- 如果浏览器禁止存储，游戏仍可运行，但不能保证跨次打开恢复。

## 源码与重新打包

本项目没有运行时第三方 JavaScript 依赖，也没有 CDN、在线字体或远程模型请求。

- `game.js`：九洞关卡、滚动物理、计分、存档、输入与界面逻辑。
- `engine.js`：WebGL 渲染、矩阵、阴影与基础几何。
- `style.css`：电脑、手机及横屏布局。
- `template.html`：界面结构。
- `assets.js`：从素材 GLB 转换的本地模型数据。
- `assets/`：本次打包涉及的原始 GLB，包含贴图目录。
- `build.py`：将上述文件重新嵌入 `index.html`。
- `convert_assets.py`：重新读取原始模型、法线及调色板，生成 `assets.js`。
- `QA_REPORT.md`、`tests/`：此次验证说明与结果。

修改源文件后运行：

```sh
python build.py
```

`build.py` 只使用 Python 标准库。仅在需要重新转换原始 GLB 时，`convert_assets.py` 才需要 NumPy 和 Pillow。

几何与调色板来自所提供的模型。为适配球径，球洞开口略微放大；球道外侧护栏和花园环境采用程序化几何。物理是跟随地表高度的滚动模型，不是通用刚体引擎；当前没有跳跃、空中飞行或多人联机。

## 可选的回归测试

游戏运行本身仍不需要 Python、Playwright 或外部依赖。仅运行自动测试时需要安装 Python Playwright 和可用的 Chromium。

```sh
python tests/run_shadow_regression.py
```

可以通过环境变量 `CHROMIUM_EXECUTABLE` 指定浏览器路径。无显示服务器的 Linux 软件渲染环境可能需要使用 `xvfb-run -a python tests/run_shadow_regression.py`。测试从内存加载离线 HTML，停止自动游戏帧循环并显式绘制测试帧，不绕过浏览器的导航策略。它覆盖控件事件与固定步长物理，不是硬件帧率测试。
